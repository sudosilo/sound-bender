Sound Bender

Sound Bender is a web page with a processing server behind it. It is for anyone who wants to stretch or shift a sound.

The bend page sends a sound to a Rubber Band processing server and plays back the result. The server runs separately from the page.

Latest change. 2026-10-24, v2026.10.24. First release. Added Sound Bender version 1, a bend page and a Rubber Band processing server.
